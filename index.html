ContextLabeler

An NVDA screen reader add-on that labels unlabeled UI elements for blind users. An LLM (Claude Haiku) proposes each label, and SPARQL ASK queries check it against an RDF/Turtle ontology before NVDA speaks it. Speech gives the confirmed category first so users can judge how far to trust the label.

90.9% category accuracy with zero ontology-invalid outputs. With the ontology gate removed, 83.6% of outputs failed.

Method and results
  • 0.82 s median latency, 1.48 s at p95.
  • A fingerprinted label store kept labels 98.4% consistent across 550 calls.
  • Found a soundness and completeness trade-off in ontology gating through a VS Code tree-item failure case.
  • App-specific ontologies extend the vocabulary from 17 to 22 categories with no code change.

Python, NVDA, Claude API, RDF/Turtle, SPARQL, RDFLib Code for ContextLabeler

CrossAssist

An on-device iOS navigation aid for low-vision pedestrians. It runs three YOLO models through Core ML, two of them custom-trained to classify pedestrian signals and find crosswalks. Vision OCR reads walk-signal countdowns, and the app speaks "cross" only after a number is confirmed.

In a pilot with three low-vision participants, all three read the walk-signal state correctly within 10 m.

Method and results
  • Depth Anything V2 estimates distance, with a pinhole camera model between depth frames.
  • One participant struggled with the countdown. The cause was small display text, not OCR error.
  • Swift 6 concurrency safe, with no third-party dependencies.

Swift 6, SwiftUI, Core ML, YOLO, Vision, ARKit Code for CrossAssist

Plan First

A human-in-the-loop checkpoint for AI creative coding. Before any generated p5.js code runs, the artist sees the model's reading of an ambiguous request such as "make it more dramatic" as editable Change and Preserve lists, and nothing changes until they approve it.

In 60 automated test cases with no human participants, naming a property in Preserve cut unwanted changes from 25 to 6.

Method and results
  • After each change, the system compares motion and dominant hue without another model call, then marks each preserved item as kept, changed anyway, or not checked.
  • The effect was strongest for color and "make it calmer" requests, and weak when a request asked to change and keep motion at once.

TypeScript, p5.js, LLM evaluation Code for Plan First

2025Course project (CPSC 583, Knowledge Representation and Reasoning), team of three

Explainable Used Car Recommendation System

An explainable recommender over 5,181 vehicles merged from Kaggle listings, NHTSA crash ratings, and NHTSA complaint data. Prolog expert rules, an RDF/OWL knowledge graph queried with SPARQL, propositional filtering, and a probabilistic reliability estimate combine so each result names the rule categories it meets.

Data limits are stated openly: about 36% of vehicles had safety ratings and 22% had complaint records.
