# shubhamjakhete.github.io

Source for my academic homepage, live at **https://shubhamjakhete.github.io**.

I work on Human-Centered AI and accessibility, focusing on AI systems that interpret and act on digital interfaces for blind and low-vision people.

## Contents

| File | Purpose |
|---|---|
| `index.html` | The site: research, manuscripts, experience, projects, education |
| `cv.pdf` | Current CV, linked from the site |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is |

## Updating

- **New CV:** replace `cv.pdf` with the new file, keeping the same name.
- **New project or paper:** copy an existing `<article class="project">` or `<li>` block in `index.html` and edit it.
- Changes go live a minute or two after pushing to `main`.

## Accessibility

The site uses semantic landmarks and headings, a skip link, visible focus styles, light and dark themes, and reduced-motion support. If you find an accessibility problem, please email shubhamsjakhete@gmail.com.

Plain HTML and CSS, no build step or dependencies.
